# RepoScroll

把值得看的 GitHub 项目变成可以浏览、搜索和收藏的信息流。

手机上是双列发现流和底部导航；电脑上自动切换为顶部导航、顶部搜索和四列内容区。两端使用同一个网址、同一个 GitHub 账号和同一份 Stars。

## 直接使用

- 网页：<https://echo-builds-starfeed.vercel.app/>
- 手机：用 Safari 或 Chrome 打开同一链接，也可以安装到主屏幕，像普通 App 一样启动。

## 网页、手机和 PWA

- 小屏幕使用双列卡片、底部搜索和底部导航；发现页持续下滑会自动加载更早的项目。
- 平板自动切换为三列；桌面切换为四列、顶部导航和顶部搜索。
- `manifest.webmanifest`、应用图标和 Service Worker 让网站可以安装到手机或电脑，并在断网时打开最近缓存的页面。
- 项目详情会生成带 `repo` 参数的独立网址，复制地址即可把具体项目分享给别人。
- 收藏由 GitHub Stars 承载，换设备登录同一 GitHub 账号即可恢复。

## 本地预览

只预览推荐与搜索页面时，可在源码目录运行：

```sh
python3 -m http.server 4173
```

打开 <http://localhost:4173>。GitHub 登录和 Stars 同步依赖 Vercel Functions，本地静态服务器不会运行 `/api`。

## GitHub 登录与收藏同步

- 用户通过 GitHub App 登录，应用只申请 Stars 读取和写入权限。
- GitHub Token 不写入前端，也不保存在 `localStorage`；后端将访问令牌和刷新令牌加密后放入 `HttpOnly`、`Secure`、`SameSite=Lax` Cookie。
- 登录后导入最多 1000 个历史 Stars，按仓库 Topics、名称和简介归入中文主题，并用于调整推荐顺序。
- 登录前的本机收藏不会自动批量写入 GitHub；页面会让用户选择是否导入。
- 在 RepoScroll 收藏或取消收藏会同步调用 GitHub Stars API。换设备后登录同一 GitHub 账号即可恢复收藏与兴趣画像。

Vercel 需要配置以下环境变量：

```text
GITHUB_CLIENT_ID
GITHUB_CLIENT_SECRET
SESSION_SECRET
```

`SESSION_SECRET` 至少 32 个随机字符。GitHub App 的回调地址设置为：

```text
https://<Vercel 域名>/api/auth/callback
```

## 推荐、更新和日期

- 发现页有两条候选链：最近 90 天创建并快速达到 1000 Star 的新项目；以及历史项目在最近 45 天发布重要 Release、总 Star 达到 5000 的重新活跃项目。仓库创建时间不再是唯一准入依据。
- 候选项目还要经过 AI 产品经理相关性和产品质量筛选。游戏反编译、越狱、普通系统修改和纯代码练习不进入主信息流；README 完整度、可体验性、社区参与和产品完成度共同决定质量。
- 第一版用“近期创建并达到高星”与“近期重要 Release”作为即时信号。从上线开始积累 Star 快照后，再加入 7 天、30 天新增 Star 作为主要热度指标，不用历史总 Star 冒充近期热度。
- 每次进入获取最新筛选结果；持续下滑加载更早的收录批次。同一个项目持续热门时不重复出现，只有发生新的重要迭代才可再次进入。
- 首页优先从 README 提取能表达产品 UI、使用方式或实际效果的图片；没有合适图片时才使用中文文字封面。
- 所有卡片统一进入 RepoScroll 站内详情页。详情页读取 README 中与产品介绍、功能、工作方式和使用场景相关的原文；中文保持原文，英文忠实翻译并保留标题、段落、列表、图片和代码结构，不做总结、删减或二次改写。
- 详情页底部保留查看 GitHub、可用时的在线体验或客户端下载安装，以及收藏。只有用户在详情页主动点击“查看 GitHub”才跳转到原仓库。无法连接时继续使用最近缓存或预载数据。登录前收藏保存在当前浏览器；登录后与 GitHub Stars 双向同步。

## 自然语言搜索

- 首页底部搜索框支持直接描述需求，例如「找能把播客翻译成中文、最好可以本地运行的项目」。请求发送到 `/api/search`，由服务端模型把自然语言拆成 1–3 条互补的 GitHub 搜索语句，再查询完整 GitHub Search API。
- 多条搜索结果按仓库合并、排除归档仓库和 Fork，并统一按 Star 从高到低排列；搜索不受首页双列内容限制，也不强制首页的 1000 Star 准入门槛。
- 模型会为返回项目生成一句中文标题和说明。模型服务暂时不可用时，后端退化为关键词规则，并在页面明确提示，不伪装成智能理解。
- Vercel 部署优先使用自动提供的 OIDC Token 访问 AI Gateway，也可以配置 `AI_GATEWAY_API_KEY`；模型可用 `SEARCH_MODEL` 替换，默认使用 AI Gateway 当前提供的免费轻量模型。
